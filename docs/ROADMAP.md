# Roadmap

- 0.2 MVP: projects, boards, draggable notes/text/tasks, autosave, portable archive, CI builds.
- 0.3: image cards, asset manager, board thumbnails, duplicate board, keyboard shortcuts.
- 0.4: rich text, columns, connectors, multi-select, undo/redo.
- 0.5: SQLite migration, backup/recovery, search indexing.
- 0.6: AI abstraction, Ollama local provider, optional cloud providers.
- 1.0: hardening, accessibility, tests, signed installers and release automation.
